# VentureAlex Toolbox

A collection of practical Python scripts for data handling, monitoring, automation, and everyday utilities.

Built for personal use but shared openly for anyone to use, learn from, or improve.

---

## Categories

### Networking & Monitoring
- **[Speed Test Logger](./networking/speed-test-logger/)**  
  Automatically logs internet download/upload speeds and latency to a CSV file at regular intervals.

### Data Tools
- **[JSON to CSV Converter](./data/json-to-csv/)**  
  Converts JSON files into clean CSV format with organized input/output folders.
- **[Google Trends Fetcher](./data/google-trends/)**  
  Pulls Google Trends interest-over-time data for analysis.

### Gardening & Planning
- **[PLANting Planner](./gardening/planting-planner/)**  
  Helps determine optimal planting times based on zip code (uses latitude/longitude lookup).

### Environment & Notifications
- **[AQI Notifications](./monitoring/aqi-notifications/)** (or wherever you placed it)  
  Sends air quality alerts based on current conditions.
