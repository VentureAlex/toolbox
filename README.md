# VentureAlex Toolbox

A collection of practical Python scripts for data handling, monitoring, automation, and everyday utilities.

---

## Categories

### Networking & Monitoring
- **[Speed Test Logger](./networking/speed-test-logger/)**  
  Automatically logs internet download/upload speeds and latency to a CSV file.

### Data Tools
- **[JSON to CSV Converter](./data/json-to-csv/)**  
  Converts JSON files into clean CSV format with organized input/output folders.
- **[Google Trends Fetcher](./data/google-trends/)**  
  Pulls Google Trends interest-over-time data.

### Gardening & Planning
- **[PLANting Planner](./gardening/planting-planner/)**  
  Helps determine optimal planting times based on zip code.

### Environment & Notifications
- **[AQI Notifications](./monitoring/aqi-notifications/)**  
  Sends air quality alerts.

---
